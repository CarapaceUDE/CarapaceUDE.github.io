Cortex

Cortex is the software platform built by Carapace: a control plane that decides which model, tool, or environment handles each request based on policy, cost, speed, and context.

You can explore it yourself, or use it as the base for a practical business deployment.

Simple version

Cortex gives you a clearer place to run AI-assisted work.

Instead of juggling disconnected tools and tabs, you get a platform that makes workflows easier to see, shape, and supervise.

Status

Cortex is still experimental software. Use controlled environments, test carefully, and keep human review in the loop.

Secure by design

The model cannot leak what it never received.

Passwords, tokens, and credentials are isolated and masked until the exact moment of execution. Models receive only the context required for the task.

Inspectability

Trust is a feature, not a promise.

Policies, approvals, routing, models, and audit logs are designed to be inspected so teams can explain, govern, and improve how AI work gets done.

How it decides

Carapace maintains a model roster spanning frontier APIs, local and open-weight models, private cloud environments, and specialized tools. Requests map to the right destination by capability, cost, speed, context needs, and company policy. If a provider changes, you route elsewhere.
