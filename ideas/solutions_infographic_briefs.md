These are ready-to-prompt briefs for replacing the current text-heavy Solutions bubbles with deck-style infographics.

- placement: `bubble`
- one-line message: Keep leads and clients from slipping between touchpoints.
- system action: Cortex watches handoffs, drafts follow-up, and routes the next step.
- business payoff: fewer dropped leads, faster response, less manual chasing.
- visual model: routed handoff map
- show:
  - incoming lead or request node
  - staged follow-up path
  - handoff checkpoint

## Prompting note

When generating a set, keep the visual family consistent:

- same type treatment
- same node and line style
- same border logic
- same lighting behavior
- same view angle

The set should feel like one system, not six unrelated posters.
